# Document Library

As part of the mandate of being the world's best source of information about pinball, we want the site to publicly host all the documentation related to each model, manufacturer and system.

Various aggregator sites already do this. IPDB has a huge trove of manufacturer documents: thousands of manufacturer manuals, handbooks, parts lists and field bulletins. Pinexplore's DuckDB analytics database already indexes them.

This is related to [DocumentCitations.md](./citations/DocumentCitations.md). We plan to pre-seed citation sources for all these documents. A next step along the same line is to physically host them as well.

Users would be able to upload docs.

Each document would be a first class citizen, with a URL-addressable web page and route for each document. The document's web page would show things like the system(s) and model(s) it's about. At some point we might allow discussion threads about the doc.

## Pinexplore web cache would be the prototype

The Pinexplore web cache work would be a prototype of how to structure it. The documents acquired in web cache would be placed directly into Flipcommons; we wouldn't go re-acquire those docs from the internet.

## Specific document types

### Patents

Flipcommons probably won't publish patents; they are already quite findable online. But we'll absolutely put them into the web cache to be used as evidence.

### Trade articles

Same with trade articles. Flipcommons probably won't publish copies, but they absolutely go into web cache, and we want to classify them.
